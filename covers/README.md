# Book covers

Put cover pictures here (jpg, png or webp, ideally about 400 px wide).
Then, in the Google Sheet's **Cover** column, write just the file name, e.g. `sphinx.jpg`.

The Cover column also accepts:
- a direct image link: `https://…/cover.jpg`
- a Google Drive share link (share the file as "Anyone with the link")

Leave the cell empty for no picture.
